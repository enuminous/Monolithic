Open IPFS gateway ↗

CAR v1 contains a canonical DAG-CBOR manifest root and raw source blocks. A local IPFS node can import the CAR using ipfs dag import monolithic-corpus.car. A gateway link works only once those blocks are actually available on IPFS.

Transport choices: browser download → USB/sneakernet → archive server → IPFS pinning. Neither a CAR export nor a CID automatically publishes data to a network.

RELAY / LIBP2P / UUCP

INTEROPERABILITY

Protocols, not promises.

libp2p: browser-to-browser authenticated transport needs js-libp2p modules, signaling and a reachable relay; this dependency-free page does not implement that full protocol. Configure a libp2p gateway/daemon separately, then exchange CAR blocks using the standard data formats.

Sneakernet: export CAR/JSON → copy to removable media → import JSON / ipfs dag import CAR. UUCP: transfer that exact CAR file over an external UUCP link. Raw TCP and UUCP are not browser APIs.
Security: the optional archive server binds to localhost by default. Never expose an unauthenticated relay or write-enabled archive to the open Internet.

SEMANTIC WEB EXPORT

RDF / OWL / JSON-LD

Readable by machines.

The ontology describes repositories, source records, categories and provenance. It deliberately makes no formal claim that a physics equation is true merely because a source exists.

RDF and OWL exports use a minimal documented Monolithic vocabulary. Wikidata and mathematical database search links do not assert equivalence.

EXTERNAL RESEARCH PORTALS

USER INITIATED

Choose a repository in the Atlas. Open contextual searches in reference databases. Nothing is bulk scraped or automatically merged into the corpus.

Wikidata: linked entities; OSM: geographical search and attribution, not a corpus map; OEIS: integer sequences; LMFDB: number-theory and automorphic-object records. External results should be cited and checked before incorporating them into any paper.

Link launch is explicit. No third-party data has been imported.
